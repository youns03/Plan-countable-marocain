# الدليل المحاسبي المغربي | Guide du Plan Comptable Marocain

تطبيق Android أصلي يساعد على استكشاف المخطط المحاسبي المغربي والتعلّم منه باللغتين العربية والفرنسية. التطبيق مصمم ليبقى مفيدًا دون اتصال بالإنترنت.

## الحالة التقنية

- **المنصة:** Android / Kotlin / Jetpack Compose / Material 3.
- **الحد الأدنى:** Android 7.0 (API 24).
- **البيانات:** بيانات المخطط المحلية داخل التطبيق، مع بحث وفهرسة وشجرة حسابات.
- **التخزين المحلي:** المفضلة، عمليات البحث الأخيرة، الحسابات التي تمت مشاهدتها، تفضيلات اللغة والمظهر وحجم الخط، وأفضل نتيجة للاختبار.
- **الاختبارات:** اختبارات وحدات وتحقق من سلامة بنية الحسابات؛ يتم تشغيلها مع بناء APK عبر GitHub Actions.

## التشغيل والتطوير

1. افتح المشروع في Android Studio حديث يدعم Android Gradle Plugin المستخدم في ملف app/build.gradle.kts.
2. استخدم JDK 17 وGradle 9.3.1 لمهام سطر الأوامر.
3. نفّذ مزامنة Gradle، ثم شغّل تطبيق app على جهاز أو محاكي.
4. بعد تثبيت Gradle، تحقق من المشروع بتشغيل الأمرين: **gradle testDebugUnitTest** و **gradle assembleDebug**.

يتحقق سير العمل في .github/workflows/android-ci.yml من الاختبارات وبناء نسخة Debug عند دفع التغييرات أو فتح Pull Request.

## بنية المشروع

- data/Class*Data.kt: بيانات الأصناف المحاسبية.
- data/PlanComptableRepository.kt: البحث، الاسترجاع الهرمي، تفكيك أرقام الحسابات وتدقيق البيانات.
- data/PreferencesRepository.kt: تفضيلات المستخدم والتخزين المحلي.
- viewmodel/MainViewModel.kt: حالة التطبيق والتفاعلات.
- ui/screens/: الشاشات الرئيسية وشاشة التعلّم والبحث والإعدادات.
- ui/components/: مكونات واجهة مشتركة.
- app/src/test/: اختبارات المنطق وسلامة البيانات.

## مبدأ موثوقية البيانات

تُعامل أسماء الحسابات وأرقامها الرسمية باعتبارها بيانات مرجعية. يجب ألا تُصحّح أي قيمة غير مألوفة بصمت؛ تُراجع مع الوثيقة المرجعية وتُعرض الملاحظات عند الحاجة. الشروح والأمثلة التعليمية يجب أن تبقى متميزة بوضوح عن نص المخطط الرسمي.

## Backend والخصوصية

هذا المشروع حاليًا تطبيق **offline-first** ولا يتطلب حساب مستخدم أو خادمًا سحابيًا لكي يعمل الدليل والبحث. تتم إدارة البيانات المرجعية والمنطق المحاسبي داخل طبقة البيانات، بينما تحفظ تفضيلات المستخدم محليًا. لا تضف خدمة سحابية أو مفاتيح API إلا عند وجود ميزة محددة تتطلبها، ولا ترفع الأسرار أو ملفات التوقيع إلى المستودع.

## قبل إصدار نسخة إنتاجية

- اجتياز بناء Release واختبارات الوحدات والاختبارات على أجهزة حقيقية.
- مراجعة جميع الحسابات مقارنةً بالوثيقة المرجعية، مع توثيق الحالات الشاذة.
- اختبار البحث العربي والفرنسي، واتجاه RTL/LTR، والوضعين الفاتح والداكن، وأحجام الخط المختلفة.
- إعداد توقيع Release بطريقة آمنة خارج المستودع.
- اختبار إمكانية الوصول، والتنقل بزر الرجوع، وحفظ التفضيلات بعد إغلاق التطبيق.
